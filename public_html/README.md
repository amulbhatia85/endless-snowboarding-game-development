# Afterglow — landing page (public_html)

A static landing page modelled on the design language of
[altosadventure.com](https://altosadventure.com/): **flat vector silhouettes**,
one continuous centred column, a blocky two-line logotype laid over the artwork,
and a single dusk hue running from the sun down into the dark.

The artwork is generated, not a photograph — `assets/hero.svg` is a layered
vector scene (six ridgelines, sun flare, framing pines, a carved rider) in
Afterglow's dusk palette rather than Alto's dawn sage. It is a 9 KB text file,
so it scales to any screen with no raster artefacts and costs almost nothing.

## Upload to Hostinger

Upload **the contents of this folder** — not the folder itself — into `public_html`.

```
public_html/
├── index.html          the page (all CSS inlined)
├── .htaccess           gzip, caching, security headers, graceful 404
├── assets/
│   ├── hero.svg        the hero artwork (9 KB vector)
│   ├── icon-192.png    favicon / home-screen icon
│   ├── icon-512.png
│   ├── apple-touch-icon.png
│   ├── og.jpg          social preview (1200×630)
│   └── screens/        ← add gameplay captures here
└── play/
    └── index.html      the full game (self-contained, ~533 KB)
```

- **hPanel → Files → File Manager** — open `public_html`, upload a zip of these
  contents, extract.
- **FTP/SFTP** — drag the contents into `public_html`.

No Node, no PHP, no database, no build step. Plain static files.

> If the domain already serves something from `public_html`, back it up first.

## Editing the hero artwork

`assets/hero.svg` is generated by a small script kept in the repo history — the
scene is deterministic (fixed seed), so you can re-tune and regenerate rather
than hand-editing paths:

| What to change | Where |
| --- | --- |
| Sky colours | the `#sky` gradient stops |
| Ridge count / steepness | the `L[]` array (`hMin`/`hMax` = peak height) |
| Sun position | `const sunX, sunY` |
| Sun flare strength | `rays()` opacity range |
| Rider size / placement | the `translate(...) scale(...)` on the rider `<g>` |

Export a raster fallback if you need one for an old client:

```bash
npx sharp-cli -i assets/hero.svg -o assets/hero.jpg resize 1600 1000
```

## Adding gameplay screenshots

Four frames sit in a 2×2 grid. Each looks deliberate while empty, and any real
image you drop in simply covers the frame — no code edit needed:

| File | Suggested shot |
| --- | --- |
| `assets/screens/01.jpg` | A crest launch, rider airborne above the ridgeline |
| `assets/screens/02.jpg` | A deep descent opening onto the valley floor |
| `assets/screens/03.jpg` | The moonlit forest, preferably mid-combo |
| `assets/screens/04.jpg` | Glowstones chained across the jungle canopy |

Use **16:9 JPEGs, roughly 1600×900, under 250 KB each**. Missing files are
ignored one at a time, so you can add them gradually.

To capture: open the game in a desktop browser at roughly 1600×900, ride to the
moment you want, and screenshot. The in-game HUD is part of the look — leave it on.

## Two things to fill in before launch

Both are single edits in `index.html`:

1. **Contact address** — search for `hello@example.com` (footer), replace with yours.
2. **Store links** — the Google Play and App Store entries are non-clickable
   "Soon" chips. When a listing goes live, change that `<span class="store">`
   into an `<a class="store" href="YOUR_URL">` and delete its `<em>Soon</em>`.

## Updating the playable game

`play/index.html` is a copy of the game's production build:

```bash
npm run build
cp dist/index.html public_html/play/index.html
```

Re-upload that one file. Nothing else changes.

## Accessibility & performance

- Semantics: header/section/footer, one `h1`, ordered headings, `<figure>` captions.
- The hero is a real `<img>` with descriptive `alt` — not a CSS background, so it
  reads correctly to assistive tech.
- Visible focus ring on every control; `prefers-reduced-motion` disables motion.
- System font stack — **no webfont request, no third-party calls, no analytics,
  no cookies.**
- Total page weight before the game: roughly 100 KB, most of it the social card
  and icons, which are only fetched when needed.
